# RankScore Exploration and Performance Evaluation

This module provides insight into Genmod rank score performance.

[Link to Genmod](https://github.com/Clinical-Genomics/genmod)

The performance scores are computed using MUTACC ground truth
variants and the evaluation schema is framed as a binary
classification problem (pathogenic vs benign).
