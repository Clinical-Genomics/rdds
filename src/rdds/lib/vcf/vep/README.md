# Variant Effect Predictor VEP Transcript Reduction Method

This module reduces the number of transcripts provided by VEP CSQ
annotation.

This is done by analysing the transcripts reported by VEP
and returns the most significant (in this case, pathogenic)
as output.

## Sorting of VEP Consequence
Sorting in this module is done according to:
https://grch37.ensembl.org/info/genome/variation/prediction/predicted_data.html#consequences
